# 实施决策

2026-10-15：用户明确授权连续完成开发，交付可以做谱、可以跟练的 Demo，无需每阶段等待确认；仅本地 Git。

## 已采用

- React + TypeScript + Vite 本地浏览器应用，无业务后端。应用只监听 127.0.0.1。
- HTML video 为唯一时间来源，视图订阅媒体时钟。保持、闪光与 SPECIAL 都是时间的函数。
- 五轨动作提示、同轨 SWAY HOLD、曲目唯一 SPECIAL；无评分或输入判定。用户新增的 STEP 为第 4 条常驻轨，替代首版仅四轨的范围限制。
- 谱面绝对毫秒时间。分段 BPM/Offset 仅改变编谱网格；移动和重新吸附为显式编辑操作。
- `1～5` 选轨、明确的录谱开关；方向键短按 TAP、长按 HOLD、Ctrl + 长按 SWAY，无需手动切换按键录谱类型。
- 修改谱面使用不可变对象；最多保留 100 次历史快照。拖动预览只在松开时提交一次历史。
- JSON 文件保存与浏览器恢复草稿并存。视频使用会话对象 URL；页面切换保留视频实例。
- 本地演示素材优先硬链接到 public，源文件保留原位置；影音、生成产物和测试截图不进入 Git。
- 使用系统中文字体和随包提供的英文字体，运行时无外部字体请求。

## 工程边界

不引入游戏引擎、独立后台播放器、服务端数据库、全盘索引、状态管理框架或桌面外壳。测试优先覆盖时间与数据不变量，浏览器测试覆盖真实 MP4 和用户完整操作链路。

## 作品整体保存与打开

2026-10-15：用户要求谱面与视频作为完整作品使用，替代初版每次手动重新配对的流程。

- `videoHint.assetId` 为可选的向后兼容字段；新作品必须关联视频后才能编辑和保存，旧版数据通过一次重新定位升级。不同文件即使同名也不自动混用。
- Chrome / Edge 的 File System Access 文件句柄保存在本机 IndexedDB，不复制视频；仅请求读取视频的权限。无此选择器时使用 IndexedDB File 缓存，存储失败不假装关联成功。
- 媒体预检在临时、不播放的 video 上读取元数据；只有视频能解码且所有谱面时间合法，才一次性提交谱面和播放来源。实际跟练仍然只有一个共享播放器和媒体时钟。
- 失去读取权限时提供重新授权；文件丢失、修改或记录缺失时重新定位。取消与失败保留原作品。草稿恢复使用同一套解析和关联流程。
- 更换视频保留音符，验证成功后重置编辑历史，避免撤销谱面元数据而不撤销播放器来源导致错配。
- 示例视频通过本地清单的名称、大小和修改时间生成固定关联 ID，只能解析到内置 `/demo.mp4`；导入作品不能指定任意 URL 或文件路径。
- 引用受当前浏览器资料和站点 origin 限制，JSON 不打包视频。移动到其他机器或清理站点数据后需要重新定位一次；未承诺跨浏览器的磁盘路径自动访问。

## 跟练与编谱 UX 修订

2026-10-15：按用户反馈，暂缓打开的立体专辑造型，优先完成操作体验。

- 跟练时隐藏主导航、文件操作、保存状态与常驻说明；只留下曲名、动作四轨、视频、播放控制和“返回工作台”。返回会暂停媒体，但保留同一个视频节点、播放位置、速度和谱面。
- 长按阈值 250 ms 使用真实按键持续时间，媒体时间负责音符起止，慢放不改变长按判定门槛。忽略重复 keydown；按下时锁定轨道和 Ctrl 状态；暂停、跳转、失焦、关闭录谱取消未完成输入。
- `F` / “反向”批量翻转上下或左右；同轴轨道可互拖。批量拖动保持行距，越出方向组时保留整组原轨道。每次操作只提交一条可撤销历史。
- 单选 TAP 后可拖动右侧手柄直接延长为 HOLD，保留原音符 ID、起点、轨道和方向，适用于全部动作轨。结束点遵循吸附与视频边界，拖动只在松开时提交一次历史；点击或取消不改类型，拖动主体仍为移动。
- 跟随默认开启且锁定，时间轴编辑不会将其关闭；解锁后可手动关闭。空格统一作为播放／暂停，即使焦点仍在复选框或按钮上。

## 五轨与视觉反馈修订

- 用户要求出拳与侧收腹之间新增 STEP，支持左右 TAP、HOLD、SWAY。序号按视觉顺序为蹲起 1、提踵 2、出拳 3、STEP 4、侧收腹 5；左右三轨可互拖。行数与 SPECIAL 位置从轨道定义推导，避免第五轨落入 SPECIAL。
- STEP 保存为 `lane: 'step'`，方向仍是 `left` / `right`，复用原有长条模型；保持 schemaVersion 1，新应用可直接读取旧四轨谱面。
- 初音绿与现有粉色通过主题变量统一；STEP 的青蓝 L / 粉红 R 在普通、保持、SWAY、编辑器与跟练中一致，SWAY 保留方向色并使用条纹。
- 到框／长条结束的反馈控制在 340 ms 和目标附近，只有四枚短粒子、光圈及轻微脉冲，无新增音效、震屏或独立动画时钟。减少动态效果偏好禁用粒子、光晕和缩放。
- 五轨跟练保持上一轮放大的音符尺寸，调整舞台高度与间距以适配 1280×720；工作台仍允许较矮窗口向下滚动。

## 统一 STEP 编辑与独立 FREE SWAY

2026-10-16：用户要求彻底移除 C、C HOLD、C SWAY，并将踏步所有类型放入同一菜单。以下规则取代此前的合腿及 C 自由摇摆方案。

- 删除旧 C 的模型、图标、样式、动作提示、示例和操作入口。读入旧谱时直接删除全部 `direction: 'close'` 音符，不保留时长、不补一拍、不转成其他音符；源文件仅在用户保存时写入。恢复草稿与导出同样经过此规则。
- STEP 的绘制与选中事件菜单均为 L · TAP、R · TAP、L · HOLD、R · HOLD、L · SWAY、R · SWAY、FREE SWAY，所有动作可直接互换。长条互转保留 ID 与起止时间；改成 TAP 清除长条字段，改成 FREE SWAY 清除跨度。操作支持撤销与重做。
- L/R 为对应脚迈步；HOLD 为对应脚单脚支撑；SWAY 为迈出后左右摇摆。独立 FREE SWAY 表示原地自由摇摆，使用 `direction: 'free'` 和白芯薄荷色 ∞，只允许 HOLD + sway；它不是旧 C 音符的重命名或兼容转换。
- 两格跨度仍由 `distance: 2` 表示，支持左右 TAP、HOLD、SWAY；单格省略此字段。FREE 不支持反向、跨度或跨轨，一格左右仍可与其他左右轨互拖。保持 schemaVersion 1。
- 快速录谱使用 ← / →，点按 TAP、长按 HOLD、Ctrl + 长按 SWAY，Shift 可组合两格跨度。↓ 创建新的独立 FREE SWAY：短按一拍，长按决定时长。按下时锁定轨道、方向和修饰键，未完成动作的取消规则不变。
- 录谱启用时，用捕获阶段接收五轨方向键和 1～5 选轨；下拉框或滑块保有焦点时仍可录入，不改变吸附、播放速度或进度。文本、数值输入仍正常编辑。
- 移除依赖合腿的双脚站位推演。STEP 检查只提示同拍和持续期间的动作冲突；不改谱、不阻止保存。
- 其余轨道继续使用 TAP / HOLD / SWAY 类型菜单和方向选择，SPECIAL 保持瞬间／持续两种类型。

## SPECIAL 五轨演出与播放性能

2026-10-16：保留五轨同步飞入和白芯荧光；修复多层实时滤镜导致的 GPU 卡顿及视频画面延迟。

- 一个 SPECIAL 事件只保存一次，五轨共享相同媒体时间。预告拍数、持续起止、同轨普通动作、连续及重叠事件逻辑不变。
- 修改前 Chrome 性能跟踪定位到 GPU 主线程的长任务；同一真实视频片段关闭 SPECIAL 后掉帧明显下降。谱面读取的 `video.currentTime` 没有累计漂移，视频画面却因 GPU 积压而晚显示，形成视觉错位。
- 发光符号、光环与碎片在开发时烘焙；爆发合并成 50 帧纹理，每个爆发只更新一块背景的位置。运行时没有碎片模糊、阴影滤镜或逐粒子 DOM 更新；五轨飞入改用 transform，不逐帧改 left。提前加载纹理。
- 50 帧对应既有 820 ms 爆发时长，直接由媒体进度选择帧；不循环计时、不补播漏掉的帧。减少动态效果只显示静态符号淡出。
- 媒体控制器最多每秒发布 60 次绘制更新，避免 120/144 Hz 屏幕重复构造整套 SVG。每次发布都重新读取媒体时间；暂停、跳转和状态事件仍立即同步，视频播放速度不变。
- 增加漏帧、停滞、变速与回拖时钟单测，以及真实 MP4 的连续 SPECIAL／五轨长条压力测试。整首 1080p 1× 播放采样视频帧时间、界面时间和五轨状态；性能测试关闭录屏式 trace，避免测量本身争抢合成器。

## SPECIAL HOLD 的连续时长表达

2026-10-16：用连续长带与尾圆替换持续 SPECIAL 的倒计时圆环，保留五轨同步飞入和既有起止爆发。

- 头尾使用事件起点所在 BPM 和预告拍数决定的同一速度，尾点独立对应 `endTimeMs`。飞入时长度表示完整时长；到框后头部固定、尾部前进。跨 BPM 段、暂停、回拖和变速均直接取媒体时间，没有新增动画计时器。
- 条身是 16×192 PNG，尾圆是 192×192 PNG，总计约 31 KB，五轨共享并预加载解码。用 transform 移动和缩放固定尺寸纹理；横向拉伸不改变纵向荧光厚度。不使用运行时阴影、SVG 滤镜、波浪计算或持续粒子。
- 可见条身的长度不超过轨道判定线距离。屏外尾点停在左边界并隐藏，直到真实尾点进入；不为超长持续事件创建巨大纹理或搬动远在屏外的图层。
- HOLD 不再绘制旧彗尾、倒计时环与头部装饰碎星。普通瞬间 SPECIAL 的演出保留；普通动作的标记位于光带上层，持续符号及爆发仍在前景。
- 短条与重叠事件各保留自己的头尾，不按视觉距离合并。减少动态效果时保留时长信息，继续禁用装饰性爆发动画。

## 已知限制

- 编辑器模式切换保留谱面与媒体时间；选择、缩放和录谱工具偏好在重新进入编辑器时恢复默认。
- 本版没有片段循环和第二主题。
- 浏览器恢复草稿只存当前最新作品；正式保存以 JSON 为准。
- 较矮窗口需要滚动查看编辑区；不提供手机布局。
