## 已实测

- 正常播放、暂停后时间冻结、前后跳转、0.5 倍速、整首自然结束。
- 全曲 1x 播放中多次读取媒体时间，检查四轨保持状态；没有观察到累积偏移。未测量跨设备毫秒级延迟或承诺帧率。
- 跳入 SWAY HOLD 中间立即显示保持，跳回之前恢复等待；SPECIAL 预告、开始与持续结束。
- 跟练／编辑切换保留同一视频实例、时间和速度。
- 鼠标点选、放置、拖长、整体移动、端点缩放、SWAY 修改、框选、复制粘贴、删除、撤销重做。
- 分段 BPM/Offset、3/4 与 4/4、吸附；改网格不挪动已写音符。
- 慢放键盘录谱、重复 keydown 不连刷、HOLD 锁定初始轨道；暂停和跳转取消未完成长条；输入框方向键不录谱。
- 唯一 SPECIAL 定义、多个持续事件、保存重开一致。
- 实际文件选择器导入本地 MP4，保存第一首后新建第二首。
- JSON 下载导出后读取文件并重新导入，比对完整内容；非法版本拒绝并保留现有工作。
- 未保存提示、浏览器草稿持久化及刷新后的恢复。
- 整个工作区全屏，四轨与视频同时可见。
- 1280×720 与 1920×1080 无页面水平溢出；较矮窗口编辑器允许垂直滚动。
- 生产构建从 4173 端口实际载入并播放 1080p 视频，媒体元素无解码错误。

## 限制与复现

- 自动化验证了 JSON 下载保存；原生“另存为”文件选择对话框及操作系统权限交互没有在自动化中覆盖。浏览器不支持原生保存接口时会回退为下载；也可始终使用“导出 JSON”。
- 完整歌曲验证使用当前目录中的素材。换其他编码的 MP4 仍需浏览器实际解码验证。
- 示例谱是功能演示，不代表视频中每一个动作都已人工对齐。
- 浏览器测试失败时会保留截图与 trace；通过测试的布局截图位于 `artifacts/`。这些运行产物不提交到 Git。

复现命令和操作说明见根目录 README。测试运行时不读取个人 Chrome 资料。开发服务器忽略浏览器报告和测试截图变化，避免生成报告时刷新用户工作区。
