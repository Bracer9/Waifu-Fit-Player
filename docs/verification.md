## 限制与复现

- 自动化验证了 JSON 下载保存；原生“另存为”文件选择对话框及操作系统权限交互没有在自动化中覆盖。浏览器不支持原生保存接口时会回退为下载；也可始终使用“导出 JSON”。
- 完整歌曲验证使用当前目录中的素材。换其他编码的 MP4 仍需浏览器实际解码验证。
- 示例谱是功能演示，不代表视频中每一个动作都已人工对齐。
- 浏览器测试失败时会保留截图与 trace；通过测试的布局截图位于 `artifacts/`。这些运行产物不提交到 Git。

复现命令和操作说明见根目录 README。测试运行时不读取个人 Chrome 资料。开发服务器忽略浏览器报告和测试截图变化，避免生成报告时刷新用户工作区。
