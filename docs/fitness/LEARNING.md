## 提取规则与限制

1. 四轨，保留原 HOLD／SWAY 时长、回位及同时配合的手臂，不随机拆轨拼接。
2. 不再按最少4个音符过滤长段落；按动作模式分层，并逐一核对原长动作，避免按常见轨道组合挤掉稀有动作。
3. 2／4／6／8小节窗口，不截断长条；完整长动作可以只有1～2条记录。TAP周期仍须回位；原谱按长条结束且无独立回位音符的记录保持原样。
4. entryPose／exitPose仍为继承字段，未建成可靠的跨段姿态模型，不能当成人工已确认的站姿标签。HOLD→SWAY连续低姿态是必须保留的反例。
5. activity新增持续拍数项，但权重仍是实验启发式，不是学习得出的专业运动强度，更不是医疗／训练处方。
6. 模板去重和镜像只解决词汇完整性；曲式解析、音乐段落功能与动作负荷的联合学习及验证仍是独立必需环节。
