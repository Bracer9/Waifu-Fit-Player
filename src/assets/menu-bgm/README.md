# 主界面 BGM

将游戏自带的 MP3、OGG、WAV 或 M4A 放在本目录（不含子目录）。文件名去掉扩展名就是菜单中的曲名，按文件名排序。

这些音频属于游戏 assets，应随 Git 提交。添加或删除文件后重新启动正式版（`npm start` 会重新构建），无需手写播放列表。

主菜单与专辑列表共享主题音乐；单曲选择试听已发布作品的 MP4 音轨，不需要另备 MP3。

加载由 `useMenuMusic.ts`／`menu-bgm-source.ts` 管理：仅保留当前曲目的完整压缩 Blob，下一首下载成功后才释放旧 URL。空响应、不完整 Range、临时 HTTP／网络错误会绕开旧缓存完整重试一次；失败不循环重试或自动跳歌，点击当前曲目可重新加载。换曲或离开场景会取消未完成请求，旧请求不会覆盖新选择。
