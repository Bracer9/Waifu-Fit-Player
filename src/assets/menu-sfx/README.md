# 菜单音效

与 `../menu-bgm/` 一样随 Git 打包；均为本项目合成的原创电子短音，无外部素材依赖。

- `mode.wav`：主菜单音游／创作卡片。
- `album.wav`：进入专辑。
- `insert.wav`：专辑卡片完全入槽时的 0.19 秒塑料卡扣声，轻微摩擦和两段圆润卡扣，峰值 0.66；只在飞入动画完成后播放一次，不叠加普通确认音。沿用全局 SE 音量。单独执行 `node scripts/generate-album-insert-sfx.mjs` 可重新生成。
- `song.wav`：点击单曲或打开开始确认。
- `settings.wav`：设置、耳机菜单、循环方式、BGM 选择与播放暂停、谱面类型和曲目切换。
- `back.wav`：返回、关闭叉号、取消和 Esc 关闭，共用一个下降短音。
- `charge.wav`：开始确认页按住 Enter／鼠标时的 1.15 秒上升充能音，松开、取消、失焦或切换谱面立即停止。素材增益提高 50%，仍受全局 SE 音量控制。
- `release.wav`：已开始充能后松开 Enter／鼠标，播放 0.26 秒泄压气声和下降机音；极短点击、失焦、取消与切换类型不额外叠加泄气声。
- `charged.wav`：充满时的 0.34 秒轻柔启动音，使用缓起音的温暖纯音，峰值 0.18；没有撞击、噪声或失真层。配合 bar 背光亮起及圆环滑到右端的 420ms 演出。
- `liquid.wav`：主菜单↔专辑选择的 2.46 秒轻柔气泡音，以圆润上扬的小气泡为主、极轻的水下空气声为底，配合覆盖和退潮；峰值约 −10.9 dBFS，与触发导航的点击音叠加，结束或中断转场时停止。首次启动的视觉开场不尝试自动播放音效。

44.1 kHz、16-bit 单声道，普通短音 85–190 ms，充能音 1.15 秒，液体音 2.46 秒，十段合计约 448 KB。由全局设置的「音效（SE）音量」独立控制，默认 50%，设为 0 即静音；与菜单 BGM、游戏／视频音量互不影响。普通 UI 短音快速连点会中断上一段；液体音使用独立的一次性播放通道，保留点击音的反馈。没有运行时合成或音效动画循环。

需要调音色时修改 `scripts/generate-menu-sfx.mjs`，执行 `node scripts/generate-menu-sfx.mjs` 重新生成，也可以直接用同名 WAV 替换。

液体音单独由 `scripts/generate-liquid-sfx.mjs` 生成，使用确定性的带限噪声和短气泡音，不改写其他音效。执行 `node scripts/generate-liquid-sfx.mjs` 可重新生成。

泄气与完成音单独由 `scripts/generate-start-feedback-sfx.mjs` 生成，仅改写 `release.wav`／`charged.wav`，保留已调好的蓄能音和其他菜单音。重做全部菜单音后也需执行此脚本恢复新版启动反馈。
