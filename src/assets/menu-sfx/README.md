# 菜单音效

与 `../menu-bgm/` 一样随 Git 打包；均为本项目合成的原创电子短音，无外部素材依赖。

- `mode.wav`：主菜单音游／创作卡片。
- `album.wav`：进入专辑。
- `song.wav`：点击单曲或打开开始确认。
- `settings.wav`：设置、耳机菜单、循环方式、BGM 选择与播放暂停、谱面类型和曲目切换。
- `back.wav`：返回、关闭叉号、取消和 Esc 关闭，共用一个下降短音。
- `charge.wav`：开始确认页按住 Enter／鼠标时的 1.15 秒上升充能音，松开、取消、失焦或切换谱面立即停止。素材增益提高 50%，仍受全局 SE 音量控制。
- `charged.wav`：充满时的短促完成和弦，与完成脉冲同时触发。

44.1 kHz、16-bit 单声道，普通短音 85–220 ms，充能音 1.15 秒，七段合计约 181 KB。由全局设置的「音效（SE）音量」独立控制，默认 50%，设为 0 即静音；与菜单 BGM、游戏／视频音量互不影响。快速连点会中断上一段，避免叠加。没有运行时合成或音效动画循环。

需要调音色时修改 `scripts/generate-menu-sfx.mjs`，执行 `node scripts/generate-menu-sfx.mjs` 重新生成，也可以直接用同名 WAV 替换。
