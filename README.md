# Waifu Fit Player

个人使用的本地舞蹈视频跟练播放器与谱面编辑器。一个作品由谱面和关联视频组成，打开作品时一并恢复。React + TypeScript + Vite，共享一个播放实例；四轨提示以视频时间为准。

## 启动

本机已配置 Node.js 24。推荐 Chrome 或 Edge。

双击根目录的 **`start-demo.cmd`**，或者在项目目录运行：

```powershell
npm ci
npm run dev
```

打开 <http://127.0.0.1:5173/>。启动脚本只监听本机，不创建远程仓库、不上传文件。

- 首页点击 **体验示例作品**，再点击播放，即可跟练。
- 跟练页点击 **返回工作台**，可以修改示例或从 **新建** 开始。文件管理与编辑工具集中在工作台。
- `maps/` 中现有 MP4 会被准备为本地示例素材。这个过程优先创建硬链接，不改变源视频；不支持硬链接时复制。
- 没有示例素材也可直接导入任意兼容 MP4。
- 示例谱覆盖现有歌曲，展示四轨、普通／HOLD／SWAY 与重复 SPECIAL。**它是功能演示谱，尚未逐拍校准视频编舞。** 示例 BPM 为 150、第一拍为 2000 ms，可自行编辑。

字体随应用打包，运行界面不依赖远程字体或在线服务。视频音轨是唯一音乐来源，旁边的 MP3 不会被额外播放。

## 完成一首谱面

1. **新建并选择视频**：选择本地 MP4 后创建完整作品；取消选择保留原工作区。默认完整显示画面，不裁切。建议 H.264 + AAC。
2. **设置网格**：编辑器右侧点“节拍段”，填写 BPM 与 4/4 或 3/4。拖动视频进度后点击“当前位置设为第一拍”。后续变拍或重新对齐时，在当前位置新增段。
3. **鼠标写谱**：使用铅笔工具，选轨道和方向后点击时间轴。拖动空白处创建 HOLD；点选长条，在属性中开启 SWAY。拖动音符移动；同轴轨道 `1↔2`、`3↔4` 可互拖；拖动长条两端改变长度。选中后按 `F` 或点击“反向”翻转方向。
4. **按键写谱**：启用“按键录谱”并播放。`1～4` 立即选轨，方向键点按录 TAP、长按录 HOLD、`Ctrl + 长按` 录 SWAY，松开结束。无需切换类型，可慢放逐轨叠加。
5. **SPECIAL**：在“曲目”面板启用并定义本曲唯一的招牌动作，在细 SPECIAL 行点击或拖长，可多次出现同一动作。
6. **保存**：`Ctrl+S` 保存作品 JSON，包含谱面和视频关联；`Ctrl+Shift+S` 或下载按钮导出副本。支持文件保存对话框的浏览器可在本次会话继续写入已选择的文件；不支持时自动下载。
7. **跟练**：切换“跟练模式”，点击播放。所有动作提示自动到框；不需要按键，不计分。
8. **重开**：点击“打开作品”选择保存的 JSON，关联视频会自动载入。恢复草稿也会一起恢复视频。

## 作品与视频关联

- Chrome / Edge 使用本地文件引用，将引用记在当前浏览器中；不会复制整段视频，也不修改原视频。作品 JSON 保存稳定的视频关联 ID，不依赖同名文件猜测配对。
- 若浏览器询问读取权限，可选择“每次访问时允许”，以后自动载入；仅允许本次访问时，下次可能需要点击“允许读取视频”，无需重新寻找文件。权限行为见 [Chrome 官方说明](https://developer.chrome.com/blog/persistent-permissions-for-the-file-system-access-api)。
- 不支持文件引用选择器的浏览器，会把所选视频缓存在本地浏览器存储中，同样支持重开自动载入；这会额外占用相应磁盘空间。存储不足时会明确报错并保留当前作品。
- 旧版 JSON 第一次打开需要定位视频，重新保存后即可记住。视频被移动、删除、修改或关联记录丢失时，会显示定位窗口；取消打开保留原作品。
- 视频和谱面都验证完成后才切换作品，不进入只有其中一项的编辑状态。更换视频也必须通过媒体与时长检查，已有音符保持不变，编辑历史重新开始。
- 关联属于**当前浏览器资料和本地站点地址**。请固定使用 `http://127.0.0.1:5173/`；换浏览器、换端口、清理站点数据或将 JSON 拷到另一台电脑，需要重新定位一次。JSON 不内嵌视频，跨设备移动作品时也要携带 MP4。

## 编辑操作

| 操作               | 方法                                                     |
| ------------------ | -------------------------------------------------------- |
| 播放／暂停         | 空格或底部播放按钮                                       |
| 选择轨道           | 录谱启用时 `1` 蹲起、`2` 提踵、`3` 出拳、`4` 侧收腹      |
| 普通录入           | 方向键短按，松开写入一个 TAP，时间取按下时刻             |
| 保持录入           | 方向键按住至少 250 ms 自动录 HOLD，松开结束，不连刷      |
| 摇摆录入           | 按下方向键时同时按住 Ctrl，长按录 SWAY HOLD              |
| 反转方向           | 选中一个或多个音符，按 F 或点击“反向”                    |
| 跨轨移动           | 上下组 1↔2、左右组 3↔4 可互拖；不跨方向组                |
| 多选／框选         | Shift 点选；选择工具拖动空白区域                         |
| 复制／粘贴／剪切   | Ctrl+C / V / X；粘贴到当前视频位置并保留相对时间         |
| 连续复制           | Ctrl+D 或属性面板“复制到后面”                            |
| 全选／删除         | Ctrl+A / Delete                                          |
| 撤销／重做         | Ctrl+Z / Ctrl+Shift+Z 或 Ctrl+Y                          |
| 保存／导出         | Ctrl+S / Ctrl+Shift+S                                    |
| 取消选择、退出录谱 | Esc                                                      |
| 时间轴缩放与滚动   | 缩放滑块、底部横向滚动条；“定位播放线”可立即回到当前位置 |
| 吸附               | 每拍、半拍、四分之一拍或关闭；鼠标与录谱共用             |
| 跟随锁             | 默认锁定并开启跟随；暂停和编辑不会关闭，解锁后可取消勾选 |

文本与数值输入框内不拦截录谱快捷键。复选框、按钮和滑块获得焦点后，空格仍用于播放／暂停，不改变勾选状态。暂停、跳转、窗口失焦会取消尚未松键的录入，已完成的音符保留。

长按判定使用实际按键持续时间，音符起止始终使用视频媒体时间：0.5 倍速按住一秒，长条约占视频半秒。录入过程中切轨只影响下一颗音符；Ctrl 的状态在按下方向键时确定。开启吸附后，若长条起止落在同一网格点，结束时间延伸到下一个网格点。绘制类型和 SWAY 复选框只影响鼠标绘制，启用按键录谱时会收起。

跨轨拖动保留方向、时长和 SWAY 属性。多选拖动保持音符之间的行距；如果任意选中音符会离开自己的方向组，所有选中音符保留原轨道，水平时间移动仍然生效。SPECIAL 不参与方向翻转和跨轨移动。

**修改 BPM / Offset 只改变网格，不移动已写的动作。** 要改变动作时间，请多选后整体拖动，或主动“重新吸附”。整体移动 HOLD 保留原媒体时长，拉伸端点才改变长度。

谱面修改后会保留一个浏览器本地恢复草稿。它不是文件保存的替代品：浏览器清理网站数据后草稿可能消失。重新进入工作台可一起恢复草稿和关联视频。

## 开发与验证

```powershell
npm run check          # TypeScript 严格检查与核心单元测试
npm run format:check   # 源代码格式检查
npm run build          # 可部署静态产物（dist/）
npm run test:e2e:quick # 交互与真实媒体浏览器测试
npm run test:e2e       # 包含整首正常速度播放验证，约 5 分钟
npm run preview       # 预览构建产物，http://127.0.0.1:4173/
```

浏览器测试默认使用已安装的 Google Chrome，测试在独立临时浏览器上下文中运行。测试不会使用个人浏览器资料。失败截图和跟踪在 `test-results/`，HTML 报告在 `playwright-report/`，布局截图在 `artifacts/`，均被 Git 忽略。

`package-lock.json` 固定依赖解析结果。安装用 `npm ci`；升级依赖后重新执行检查、构建和相关浏览器测试。

## 代码结构

```text
src/
  App.tsx             工作区、文件入口、保存与恢复、页面切换
  model.ts            谱面类型、JSON 校验与序列化
  timing.ts           分段网格、吸附、音符与 SPECIAL 时间状态
  editing.ts          不可变编辑操作、撤销重做
  media.ts            共享播放实例与时间订阅
  local-media.ts      视频引用持久化、权限恢复、媒体预检与作品关联
  recording.ts        录谱快捷键及未完成 HOLD 生命周期
  demo.ts             可修改的全曲功能演示谱
  components/         箭头、动作图形、播放控制
  views/              首页、跟练四轨、时间轴编辑器
  styles.css          Pop Art 主题与桌面布局
scripts/prepare-demo.mjs  准备本地示例视频
tests/                浏览器交互及完整歌曲播放测试
```

谱面使用 `schemaVersion: 1`；时间是非负整数毫秒。四轨为 `squat`、`calf_raise`、`punch`、`side_crunch`。SWAY 是 HOLD 上的 modifier；SPECIAL 是一份曲目级定义与多个事件。未知版本、重复 ID、非法方向、无效长条和越界时间会明确报错，不静默丢弃。

播放器与编辑器共享同一谱面和视频实例。动画只读取 `video.currentTime`，不积累第二个时钟，不用独立定时器触发音符。保持状态、命中闪光和 SPECIAL 在暂停和跳转后都由目标媒体时间计算。

## 当前范围

- 支持本地浏览器使用，Git 仅本地管理；没有远程仓库。
- 没有评分、动作识别、音频分析、自动 BPM 检测或独立音轨。
- 当前提供一个 Pop Art 主题；桌面外壳、第二主题和循环片段属于后续便利功能。
- 跟练画面只保留四轨、视频、必要的播放控制及返回工作台入口；SPECIAL 只在事件附近显示。打开的立体专辑造型留待后续视觉迭代。
- 1280×720 可用，编辑器在较矮窗口中需要页面向下滚动。1920×1080 可同时查看预览与编辑区。
- 视频兼容性取决于浏览器解码器；应用不进行转码。

详细行为依据保存在 `Waifu-Fit-Player_Codex_Handoff/CODEX_HANDOFF_UPDATED.md`。其中首轮“只规划”的限制已被用户明确授权实施替代。
