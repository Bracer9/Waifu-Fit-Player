# Waifu Fit Player

个人使用的本地舞蹈视频跟练播放器与谱面编辑器。一个作品由谱面和关联视频组成，打开作品时一并恢复。React + TypeScript + Vite，共享一个播放实例；五轨提示以视频时间为准。

## 启动

本机已配置 Node.js 24。推荐 Chrome 或 Edge。

双击根目录的 **`start-demo.cmd`**，或者在项目目录运行：

```powershell
npm ci
npm start
```

打开 <http://127.0.0.1:5173/>。启动脚本只监听本机，不创建远程仓库、不上传文件。

日常写谱和跟练使用上述入口：每次启动先构建最新的优化版本，再启动服务；构建失败则停止，不运行旧产物。地址和端口固定，沿用已有的视频关联、草稿和设置。启动时请先关闭旧服务窗口；端口被占用会报错，不会自动换端口。

修改程序代码时使用 `npm run dev`，保留自动刷新与开发调试。两种方式共用源码，不能同时占用 `5173` 端口；谱面编辑功能在两种方式下都可用。

菜单和游玩画面在小窗口下以 1920×1080 为逻辑舞台等比缩放、居中留边；宽高均达到该尺寸的大窗口保留既有布局。主菜单、专辑／单曲菜单、确认卡片、倒计时和暂停共用坐标规则。工作室保留原生编辑尺寸，小窗口压缩预览高度、换行工具栏，时间轴和属性面板仍可滚动操作；Retina 的物理像素不作为布局尺寸。

- **音游模式**：先选专辑，再选歌曲和 FITNESS / 健身或 DANCE / 舞蹈谱，点击单曲卡片或按 Enter 打开开始确认页。确认页展示当前成品的曲绘、强度／难度、BPM、游玩时长、预计热量与主要动作，可用左右键或按钮切换已发布类型。按住 Enter 或鼠标启动区约 1.15 秒充能，松开平滑回退；Shift + Enter 跳过长按，直接播放完成反馈；充满后渐暗进入短暂黑场，再显出昏暗的舞台，衔接灯光通电与现有开场倒计时。Esc / Backspace 取消返回选曲。FITNESS 注重跟随音乐节奏锻炼，DANCE 注重跟随视频舞步；两者是玩法类型，不是高低难度。全部曲目包含所有已发布的歌；返回选曲会保留选择。
- **创作模式**：直接进入谱面编辑器，自动打开上次草稿；首次使用可新建或打开已有 JSON。“本地作品”管理所有草稿和发布版本。
- **继续另一类型草稿**：在“本地作品”中选择对应 FITNESS／DANCE 的“继续草稿”。工作台“谱面类型”下拉会把当前谱面复制到目标类型，目标已有草稿时询问覆盖；它不是打开另一份现有草稿的切换标签。
- **专辑试听与插入**：专辑页按 Enter／Space 或点击卡片展开右侧播放器，可试听专辑内已发布曲目、拖动进度及左右切歌；展开后 Space 暂停／继续试听，按一次 Enter 后以原有约 0.96 秒动画自动插入，松键不会取消；鼠标点击当前专辑卡片或 INSERT ALBUM 同样自动插入；播放器展开后 Shift + Enter 自动快速插入。Esc／Back、返回按钮或点击空白处先收起播放器。
- **发布**：在右侧“曲目”中设置谱面类型、专辑与曲绘。FITNESS 的运动强度由作者标注为低／中／高；DANCE 使用数值舞蹈难度。完成后点击“发布到曲库”。曲绘可上传或取当前视频画面；未设置时发布会取视频画面。专辑封面可自定义，否则从已发布曲绘中选取。
- **草稿与成品分开**：编辑和保存只更新草稿，发布才替换所选类型的成品；同曲的另一类型保持不变。“撤下发布”只从音游模式移除，保留草稿；“从 WAIFU 删除”删除整曲的两种谱面及曲绘，并清理不再使用的视频关联，保留磁盘原文件。
- **旧数据兼容**：本地曲库和导入 JSON 的 Normal 自动迁移为 FITNESS、Hard 迁移为 DANCE；没有标注的旧谱默认 DANCE。原数值难度保留为舞蹈难度，不自动推断运动强度；迁移后的健身谱强度显示为未标注，作者可在工作台补充。音符、视频关联、区间、曲绘和两套草稿／发布版本保留。
- `maps/` 中的曲包自动识别，只在本地保存，不纳入 Git。启动准备的媒体链接仍保留旧作品的视频兼容性。

主要英文字体随应用打包，运行界面不依赖在线服务。游玩声音直接来自视频，旁边的 MP3 不会额外播放。主题 BGM 放在 `src/assets/menu-bgm/`，支持 MP3、OGG、WAV、M4A，文件名即曲名，随 Git 管理；添加后重新启动正式版即可自动进入列表。鼠标悬停主界面底部耳机时，三栏音乐菜单向上展开，未固定时移出菜单后折叠，点击耳机固定，再点一次收起并取消固定，背景不变暗。左栏显示曲名、播放／暂停、可拖动进度与时间，中栏选曲，右栏选择随机／单曲循环／列表循环并调节 BGM 音量；点击音量图标静音／恢复原音量，固定提示短线随静音变灰。也可用键盘聚焦耳机、Tab 进入菜单、Esc 收起。全局设置分别记住菜单 BGM 和游戏／视频音量，后者与播放器滑条同步，也用于单曲试听。主菜单到专辑列表连续播放主题 BGM；进入专辑后试听当前单曲的 MP4 音轨，返回专辑列表从暂停位置恢复主题音乐，切曲时先淡出再淡入。进入编辑或游玩时菜单音频停止。

工作台右侧「曲目 → 视频偏移 / ms」可设置 **−1000～+1000 ms**，精度 1 ms：正值让视频与声音相对谱面延后，负值提前。支持归零，随作品保存和恢复；只改变播放时的相对位置，不改动已有音符、BPM 或网格参数。

菜单键盘操作：首次进入和返回主页时默认选中音游模式；按右依次选择创作模式、右上齿轮。卡片按下展开耳机菜单，默认高亮第一首曲目；第一首按上回到耳机，再按上回原卡片。耳机按钮按 Enter 固定，再按收起并取消固定。专辑首项按上、单曲按上可选择齿轮，Enter 打开／收起设置。齿轮被鼠标或键盘选中时都有轻微音乐呼吸效果；鼠标实际移动与键盘操作始终由后一次接管唯一高亮。

主菜单、专辑与单曲页点击右上齿轮，从原有粉色几何展开设置，不移动或缩小主卡片。悬停 **AUDIO / SYSTEM** 标签切换：AUDIO 调节菜单 BGM、游戏／视频、SE 三路音量，菜单 BGM 与耳机面板共用；SYSTEM 调整音符流速。点击设置外部、再次点击齿轮或按 Esc 收起。展开时白色棱线、网点和齿轮提示随几何出现，背景边缘继续跟随当前音乐律动。

菜单点击音效位于 `src/assets/menu-sfx/`，与 BGM 一样随 Git 管理。五段原创电子短音用于卡片、专辑、单曲、设置及返回／关闭等操作；全局设置中的 SE 音量独立控制，默认 50%，不跟随 BGM 或视频音量。可直接替换同名 WAV，或运行 `node scripts/generate-menu-sfx.mjs` 重新生成。

专辑试听播放器每次展开或切换专辑时随机选择该专辑内已发布曲目，每首播放正中间的 30 秒；播完随机换下一首，有多首时不连续重复同一首，只有一首时循环，进度条显示这段的 00:00～00:30；不足 30 秒则使用全部时长。曲目设有游玩区间时，在该区间内取中间片段，否则按视频全长计算，不做音频分析或生成额外文件。播放器展开后，歌曲以 25% 原声、75% 隔门式低通音色混合，减弱闷声效果；首次展开时播放启动咬合声，展开期间持续轻微马达循环；切换专辑或暂停试听不重启、不停转，收起时停止，机械声受 SE 音量控制。插入专辑进入单曲选择后接续同一首、同一进度的 30 秒片段，仅平滑恢复原声音色，不重新加载；单曲页切歌试听各自的中间 30 秒，播完循环当前曲目。片段末尾 700ms 平滑淡出后再循环或换歌，不新增片段开头淡入；插卡延续当前进度，复用已有播放检查，不新增音频分析或计时循环。只有进入 HOLD 确认画面才从游玩区间开头（未设置时为视频开头）预览完整区间，退出确认后恢复中间片段。机械声音为离线生成的原创 WAV，运行 `node scripts/generate-player-sfx.mjs` 可重新生成；滤波与音效参数集中在 `src/album-preview-audio.ts`。

自然曲终（包括游玩区间结束）先留约 300ms 收完最后一拍的音符消散，再进入同一舞台内的 After Show：左侧展示时长、BPM 和明确标注的估算热量，右侧保留末帧，播放控件收起。ENCORE 沿用暂停页 Restart 的准备与倒计时；NEXT TRACK 按当前专辑顺序切到另一首，单首时禁用；BACK TO SELECT／Esc 返回并保持选曲。支持方向键、Enter、鼠标，以及标准手柄方向／摇杆、A 确认、B 返回，不做分数或竞技评价。右侧在曲终立即以快门声和短暂闪光将当前末帧收成一张微倾斜的奶油纸框纪念照，背后保留轻度暗化／模糊的原画面；照片仅临时显示，离开即清理，不额外保存图片，截图不可用时保留原末帧。 照片定格后有间歇斜向反光，左侧按钮、数值与粉青斜带随 BGM 律动；选中按钮以黑框、隔边、投影和抬升突出。背景灯光独立缓慢呼吸，与 BGM 无关。照片成形后从屏幕两侧喷出一次彩带并播放庆祝 SE，在庆祝音收尾时平滑接入并循环 `src/assets/result-bgm/Sparkling Game Loop.m4a`；结束音乐沿用 BGM 音量，庆祝声沿用 SE 音量，离开时清理。

键盘展开耳机菜单时，默认高亮 TRACK SELECT 的第一首曲目，只定位、不切歌，Enter 才执行选曲。左右跨栏，上下选择曲目，**Enter** 执行播放／暂停、选曲、播放模式或静音。进入音量条后左右每次调整 5%，Enter 确认；确认后左移到静音按钮，上移回刚才的播放模式。菜单边缘按上下可回耳机，Esc / Backspace 收起并取消固定。进度条保留鼠标拖动，不参与方向键导航。

齿轮设置在主页、专辑和单曲页共用键盘操作：齿轮展开后按 ↓ 到标签，左右切换 AUDIO / SYSTEM；↓ 或 Enter 进入设置项，上下选项、左右调整，Enter 确认。音量每次调整 5%，音符流速每次调整 0.5。第一项按 ↑ 回标签，标签按 ↑ 回齿轮；Esc / Backspace 收起，焦点回到齿轮。鼠标移动到另一项时接管焦点。

## 曲包：下载、搬家与分享

**作品现在直接保存在磁盘 `maps/`。** 已在 maps 中的视频直接使用；在其他位置选择的视频会复制一次到新曲目文件夹。视频旁的 `project.json` 记录作品信息，`wfp-dance-draft.json`／`wfp-fitness-draft.json` 保存草稿，`wfp-*-released.json` 保存发布版，曲绘也在同目录。整份 maps 可以直接备份或搬家，不依赖浏览器数据。升级这一存储版本后需重启 `npm start` 本地服务；不要在仍有未保存修改时刷新旧页面。

将曲包 ZIP **解压**到项目的 `maps/` 目录，启动或刷新游戏后即可选曲；支持多层文件夹，不需要逐首导入、关联视频或重新发布。Windows 和 macOS 都使用包内相对路径，项目可以放在不同位置。第一次升级到支持曲包的版本时，请重启 `npm start` 服务以启用本地目录读取。

在工作室的 **本地作品 → 导出曲包**，下载一首歌的 `.wfp.zip`。它包含该歌曲已发布的 FITNESS／DANCE（至少一种）、原视频、曲绘、专辑归属与自定义专辑封面；同一视频只打包一次。草稿不随分享曲包发布，普通“导出 JSON”仍用于谱面备份。ZIP 使用无损存储，不重编码媒体，单包需小于 4 GB。

```text
maps/
  Sunlight/
    song.json
    video.mp4
    fitness-cover.webp
    fitness.wfp.json
    dance.wfp.json
```

`song.json` 的最小示例（通常由导出自动生成）：

```json
{
  "format": "waifu-fit-player-song",
  "version": 1,
  "id": "11111111-2222-4333-a444-555555555555",
  "title": "Sunlight",
  "video": "video.mp4",
  "cover": "fitness-cover.webp",
  "album": { "id": "anime", "name": "动漫" },
  "charts": { "fitness": "fitness.wfp.json", "dance": "dance.wfp.json" }
}
```

每个类型也可用 `{ "file": "dance.wfp.json", "video": "other.mp4", "cover": "dance-cover.webp", "album": { "id": "pop", "name": "流行" } }` 覆盖公共资源。BPM、偏移、区间、强度／难度和全部音符继续保存在对应谱面 JSON 中。

现有旧目录也兼容：将 `.wfp.json` 与 `videoHint.fileName` 指定的 MP4 放在同一个歌曲文件夹；只有一张文件名含 `cover` 的 PNG／WebP／JPEG 时自动使用。旧文件缺少类型时按原规则归为 DANCE，缺失的专辑信息仅出现在“全部曲目”，不猜测评级。

旧 song.json／.wfp.json 曲包继续读取；编辑后生成 project.json 和上述托管谱面，不覆盖作者的原始导入 JSON。存在 project.json 时按其引用读取草稿与发布版。在 WAIFU 内删除作品会把隐藏状态写入磁盘，原视频和谱面文件保留。直接编辑托管谱面 JSON 后刷新可读取；保存时若发现外部修改或另一窗口已保存，会拒绝陈旧覆盖。没有谱面、只有视频的目录不会自动成为可玩歌曲。

## 跟练画面

选曲确认完成后，黑场内先显示沿用专辑调谐转场样式的准备进度；等视频首帧、图片／字体与场景绘制准备完成，再显出房间并启动倒计时。右侧使用当前发布版本的曲绘铺满、轻微模糊并压暗，显示 **3 → 2 → 1 → GO!**；缺少曲绘时沿用现有占位图。视频首帧、动作素材与菜单音乐淡出准备好后，先让灯光与轨道启动 0.6 秒，再显示数字并开始约 2.4 秒的倒计时；五轨依次通电、扫亮。**GO 出现时立即开始视频与音频播放**，封面通过约 300ms 的电视切片／扫描线 glitch 退出；Esc / Backspace 可在准备及倒计时期间返回选曲。节拍音效沿用 SE 音量，减少动态效果时保留计数与普通淡出。时长、模糊、遮罩及轨道错开参数集中在 `src/ready-countdown.ts`。

跟练时按 **Esc / Backspace** 或点击右上暂停图标，会暂停视频、熄灭舞台灯光，让房间暗回开场前的程度，并打开右侧暂停菜单；视频下方播放器的暂停键与这个菜单共用播放状态。**空格**只切换媒体播放／暂停，不打开暂停菜单、不重放倒计时；暂停菜单打开时忽略空格。菜单从上到下为 **BACK TO SELECT、RESTART、EDIT IN STUDIO**，用上／下选择、Enter 确认，也可鼠标悬停和点击。BACK TO SELECT 返回选曲并保留当前曲目与谱面类型；RESTART 回到游玩区间起点（未设区间则为视频开头），重新播放开场倒计时；EDIT IN STUDIO 保持当前视频位置，进入当前谱面的工作室编辑，发布版本不变，覆盖不同草稿前沿用原确认。暂停菜单内按 **Esc / Backspace** 恢复，重新播放灯光、轨道启动和倒计时，到 GO 才从暂停位置继续；恢复倒计时中按 Esc / Backspace 返回暂停菜单。拖动下方进度条只跳转位置，不重放倒计时。

暂停、继续、重开、返回选曲和暂停菜单选项切换均复用现有 UI 音效，由全局 SE 音量控制；鼠标停留在同一选项时不会重复发声，SE 为 0 时静音。

主菜单、专辑或单曲页的齿轮「SYSTEM」可调音符流速 **0.5～10**，默认 **3** 对应原有流速。数值越大，音符移动越快、间距越大；不改变音乐、视频或判定时间。预览与跟练共用设置，偏好保存在当前浏览器，所有曲目通用。

跟练采用参考图中的折页专辑构图：左页为五条动作轨道，右页为视频，中央书脊、独立透视、纸板厚度与地面阴影形成开合感。粉色／青色背景、粗体封面和手写标题延续参考图风格。SPECIAL 出现时临时使用曲名栏，不额外占用轨道空间。

场景包含顶部舞台射灯、硬边纯色几何地板、有织纹和厚度的运动垫。两页围绕中央书脊分别旋转，外侧底边向前展开，形成可测量的空间夹角。专辑留出底部空间，前景不会遮挡轨道或拦截操作。背景素材随项目本地加载，生成提示词和素材路径见 [美术记录](docs/art-direction.md)。

跟练方向音符使用白色实心、粗荧光色边与细白外缘；普通方向和 STEP 共用箭头，两格踏步使用双箭头，FREE SWAY 使用 ∞。STEP 颜色表示用脚，方向由箭头单独表示。每轨只有一条中心线，不按密度拆行或缩小音符。跟练与工作台使用相同符号，TAP／FOLLOW／FOLLOW SWAY／HOLD／SWAY／FREE SWAY 在同一菜单中互换。

STEP 的 FOLLOW 表示指定脚朝箭头方向跟上并拢：同大小、同配色的空心粗荧光断线箭头，尖端完整。它可自由放在任意拍点，仅支持 TAP；在类型菜单选择 `FOLLOW`，方向和用脚颜色单独选择，可与现有 STEP 动作互换。 FOLLOW／FOLLOW SWAY 默认勾选「虚线连接前一个音符」，以细直虚线连接前一颗 STEP，中间显示正常尺寸脚印；可在绘制／录谱工具设置新音符，或在属性面板逐颗取消。开关随谱面保存，旧谱默认勾选。

`FOLLOW SWAY` 位于 FOLLOW 下方，表示跟脚并拢后持续摇摆：沿用空心断线箭头，连接 SWAY 波浪长条，可选择 L／R／BOTH。绘制时拖出时长，单击生成默认一拍，属性面板可调结束时间；录谱使用 Ctrl + Alt + 长按 ←／→。普通 Alt + ←／→ 仍为单次 FOLLOW。

左右 STEP SWAY 的光带中段带白色鞋底印，提示沿箭头方向滑过去；工作台使用相同鞋印。鞋印随音符移动，空间不足或接近其他标记时隐藏避让。FREE SWAY 仍表示原地摇摆，不显示滑步鞋印。

SQUAT 的 HOLD 中段显示上下两层白色粗线、约 120° 的宽角向下箭头头部，没有箭身；尺寸大于鞋印和手掌，提示保持蹲下。它固定在长条中点，到判定线时自然裁切消失；工作台预览和时间轴同步显示。

SIDE CRUNCH 作为重音动作使用更宽厚的箭头；颜色独立表示抬起的腿：**L 左腿蓝色、R 右腿粉红**，左右腿都可向左或向右做动作。绘制工具、属性面板和录谱均可单独选腿，H 切腿色，F 只反转箭头方向；TAP / HOLD / SWAY、复制和保存保留腿色。旧谱面仍按原方向确定默认腿色。TAP 带短收尖拖尾，临近判定的 650 ms 内有收紧的角形亮边。命中时白芯短闪、横向冲击光带与四枚斜向碎光快速展开再消散；HOLD / SWAY 开始与结束使用稍收敛的版本。爆发替换普通命中粒子，每轨同时最多一个，使用预烘焙的 32 帧小图集，播放时不新增实时模糊、阴影或独立计时器。暂停冻结、跳转直接按视频进度选帧；减少动态效果时保留静态淡出。素材可用 `node scripts/bake-crunch-impact.mjs` 重新生成。

HOLD 为直线荧光带，SWAY 为连续 SVG 波浪带，尾端是白色实心圆心、轨道色环与细白外缘。辉光由低透明度矢量描边叠加，避免移动／裁切长条的实时 blur 在首次播放时造成 GPU 长帧；白边仍保留。光带末端自然收尖；波浪相位按完整音符时长确定，剩余部分不会重新拉伸。只有时间精确首尾相接的长条共用交接点，有间隔或时间重叠的独立音符保留各自尾圆；重叠光带在其他动作标记周围留白。所有圆点与箭头位于光带之上。新箭头靠近判定线时，旧的保持提示让位；同时保持多条时，判定位置显示最近开始的动作，所有音符的时间与计分保留。暂停和跳转仍使用视频时间。左侧五轨继续使用统一的纯色标签。

同轨 TAP 精确放在 HOLD / SWAY 的结束时刻时，会成为光带一体连接的尾端箭头。例如“向下 HOLD → 向上 TAP”直接提示蹲下保持后立即起身；不需要额外开关，原音符时间和计分保持独立。有间隔或重叠的音符不会自动连成一体。

左页 `CALORIES` 按已经通过判定区的动作权重与保持时长累计参考消耗，显示到 0.1 kcal；这不是每次固定增加 0.1。各曲共用系数，算法见 [HLD](docs/HLD.md#卡路里参考值)。`FULL COMBO` 默认全部命中：TAP +1；HOLD / SWAY 起点 +1，从起点开始每持续半拍 +1，结束 +1。尾端和持续计数重合时只计一次尾端；不足半拍的长条仍计起点与结束。跨 BPM 段时按实际经过的拍数连续计算，所有轨道（包括 STEP 与 FREE SWAY）规则相同。持续时判定圈随计分半拍轻微脉冲。暂停冻结、跳转后重算，不使用独立累加计时器，也不增加按键判定。

SPECIAL 的白芯荧光、五轨飞入、爆发与持续提示使用本地预烘焙纹理；播放过程中不再为碎片、光环和符号计算实时模糊／阴影。爆发按媒体进度选取 50 帧纹理中的当前帧，暂停冻结、回拖重现，漏帧后直接显示最新位置。渲染通知上限为 60 Hz，视频和音频按原速度播放；所有谱面时间仍直接读取 `video.currentTime`，没有按帧累加的游戏时钟。

需要改动效果素材时运行 `node scripts/bake-special-sprites.mjs` 重新烘焙；这只在开发时运行，不占用游戏播放时间。

SPECIAL HOLD 由白芯符号、粉色荧光长带和白芯尾圆连接，青色细边作为强调。长度对应真实持续时间；符号到框停留，尾端继续前进，结束时汇合并使用既有释放演出。两张共享小纹理替换原倒计时圆环及 HOLD 的装饰彗尾／碎星，不新增实时滤镜或粒子。超长条只绘制可见部分；减少动态效果仍保留表示时长的长带。可用 `node scripts/bake-special-sprites.mjs --hold-only` 单独生成长带素材。

对照负载可在开发服务运行时执行 `node scripts/measure-special-hold.mjs 对照名称`，每组使用固定 1080p 合成视频采集三轮，结果保存到 `artifacts/对照名称.json`。测量时停止其他自动化浏览器任务；该压力场景同时包含五轨超长音符和重叠 SPECIAL，不能当作真实舞蹈视频的解码负载或普通谱面的平均性能。

右页视频窗口固定为 **16:9**，播放控制收在其下方；Chrome 全屏也保持相同比例。视频始终完整显示，不裁切人物或拉伸画面。较窄的竖屏会将两页上下排列。工作台保持平面布局，切换时保留同一个视频元素、进度。

跟练长条的光带与箭头／自由摇摆符号共用整体外轮廓，连接处不单独描边，白色实心动作符号仍保留。全屏使用浏览器 F11；返回工作台保留视频进度。

项目远程仓库为 [Bracer9/Waifu-Fit-Player](https://github.com/Bracer9/Waifu-Fit-Player)。同步前用 `git status` 与 `git branch -vv` 确认当前分支和未提交改动。

## 完成一首谱面

1. **新建并选择视频**：选择本地 MP4 后创建完整作品；取消选择保留原工作区。默认完整显示画面，不裁切。建议 H.264 + AAC。
2. **设置网格**：编辑器右侧点“节拍段”，填写 BPM 与 4/4 或 3/4。拖动视频进度后点击“当前位置设为第一拍”。后续变拍或重新对齐时，在当前位置新增段。
3. **鼠标写谱**：使用铅笔工具，选轨道、方向和绘制类型（TAP / HOLD / SWAY）后点击或拖动时间轴。TAP 模式拖动空白处也可创建 HOLD；选中单个普通音符后，可向右拖动其右侧手柄直接延长为 HOLD，保留起点与方向，支持 STEP。选中音符，在右侧“类型”下拉菜单中转换 TAP / HOLD / SWAY；HOLD 与 SWAY 互转保留起止时间。拖动音符主体移动；可拖往支持相应方向的轨道，批量移动保留行距；拖动长条两端改变长度。选中后按 `F` 或点击“反向”翻转方向。
4. **按键写谱**：启用“按键录谱”并播放。`1～5` 按从上到下的顺序立即选轨：SQUAT、ARMS、STEP、CALF RAISE、SIDE CRUNCH；游戏与工作台保持相同顺序。方向键点按录 TAP、长按录 HOLD、`Ctrl + 长按` 录 SWAY，松开结束。无需切换类型，可慢放逐轨叠加。
5. **SPECIAL**：在“曲目”面板启用并定义本曲唯一的招牌动作，在细 SPECIAL 行点击或拖长，可多次出现同一动作。跟练时，对应爱心／星星／闪光符号会在五轨同步飞入并爆发，持续 SPECIAL 在结束点再次散开。
6. **保存**：修改后自动写入 maps 曲目目录的草稿 JSON，`Ctrl+S` 立即写盘；`Ctrl+Shift+S` 或下载按钮另导出 JSON 副本。草稿不覆盖发布版；磁盘写入失败会明确提示。
7. **试玩与发布**：“试玩谱面”预览当前草稿；“发布到曲库”保存所选类型的独立成品。音游模式只读取成品。
8. **重开**：创作模式自动载入最近草稿与视频，也可从“本地作品”选其他草稿，或“打开作品”导入 JSON。

“节拍段”的 BPM 旁可点击**检测**，在本机后台分析当前视频音轨，成功后自动填入当前段，支持撤销。检测从本段起点开始，最多读取 90 秒，在下一段前停止，范围为 55～220 BPM；没有音轨、音频不足 6 秒或节拍不清晰时提示并保留原值。检测不改变视频播放位置、第一拍位置或已有动作时间；复杂节奏可能出现倍速／半速估计，仍可手动校正。

“曲目 → 游玩区间”可设置发布时使用的视频起点、终点，支持输入 `03:41.000` 或秒数，也可点击“用当前位置”。默认使用完整视频；“完整视频”可恢复默认，修改支持撤销并随草稿／发布版本独立保存。时间轴红线提示游玩终点，工作台仍保留、播放和编辑完整视频及所有动作。音游从起点开始、到终点停止，进度与曲目时长显示区间长度；单曲试听也只循环该区间，区间外动作不参与显示、连击或卡路里。跨边界的 HOLD、SWAY、SPECIAL 长条会在发布前列出并提供定位，需要调整后才能发布；区间内没有动作也不能发布。原视频文件、音符时间、第一拍位置不变。

## 作品与视频关联

- 视频与作品关联记录写入 maps 中的 project.json，新作品不再将视频文件／句柄写入浏览器数据库。
- 已在 maps 的 MP4 按大小与毫秒修改时间唯一匹配，直接采用其所在目录；外部 MP4 在导入时流式复制一次，播放仍通过 HTTP Range 分段读取。
- MP4 在曲目目录内改名后，按原大小／修改时间唯一恢复关联，保存时更新实际文件名；存在多个候选时要求明确定位，不猜测。
- 旧浏览器作品在首次加载新版时迁入 maps；核对落盘并在 `.wfp-backup/browser-*.json` 保留原始谱面与元数据后，保留旧浏览器作品、专辑和视频记录，等用户检查确认后再清理。失败的原数据保留并提示，不能假称迁移成功。
- 视频和谱面都验证完成后才切换作品，不进入只有其中一项的编辑状态。更换视频也必须通过媒体与时长检查，已有音符保持不变，编辑历史重新开始。
- 已迁移作品不再依赖浏览器资料或端口；换浏览器、清理站点数据不影响 maps 文件。尚未迁出的旧记录仍需在原浏览器和地址打开新版一次。纯静态部署没有本地写盘服务，保存会明确报错，不退回浏览器保存。详细约定见 [maps 存储说明](docs/MAPS-STORAGE.md)。

## 编辑操作

工作台的“区间循环”用于反复预览同一段：两个标记都在时间轴上沿，拖动漏斗的**上半 A** 设置起点、**下半 B** 设置终点；重合时拼成完整漏斗，范围为空，自动关闭循环。拖开后开启“区间循环”并播放。范围跟随当前吸附设置，按住 Alt 拖动可精细调整；拖到边缘会自动横向滚动。视频与声音一起回到起点，支持暂停，也兼容视频 offset。切换到跟练或打开另一首作品后退出循环；范围仅用于当前工作台，不写入谱面。

A / B 输入框可直接填写位置，回车确认：`1.128` 对应时间轴第 1 段第 128 小节，`1.128.3` 指定第 3 拍；单填 `128` 默认第 1 段。也可填 `03:12.500` 或 `192500ms` 精确定位，输入不受吸附限制。输入后自动显示对应时间并滚动至该标记。输入起点超过原终点时会顺带后移终点，方便直接换到很远的范围。

| 跟随锁             | 默认锁定并开启跟随；暂停和编辑不会关闭，解锁后可取消勾选                       |

文本与数值输入框内不拦截录谱快捷键。录谱开启后，方向键与 1～5 选轨优先于下拉框、按钮和滑块；不会因为选择吸附或类型而失效。复选框、按钮和滑块获得焦点后，空格仍用于播放／暂停，不改变勾选状态。暂停、跳转、窗口失焦会取消尚未松键的录入，已完成的音符保留。

第 2 轨 **ARMS / 手臂** 提供八方向箭头、L/R 拳套与 L/R/BOTH 前伸手掌。箭头表达动作方向，可选 ANY 未指定、L 左手、R 右手、BOTH 双手；拳套表示对应手向前出拳，L/R 固定为蓝/红。前伸用无手套的手掌表示，左掌蓝色、右掌红色、双掌紫色；左手拇指在画面右侧、右手拇指在左侧，拳套使用相同左右关系，字母保持正向。F 反转方向或互换单手拳套／手掌，箭头的用手颜色不变；H 单独循环箭头用手，支持多选。TAP 为单次动作，HOLD 为到位后保持，SWAY 为持续摆动。绘制和属性面板共用动作选择器，可在拳套、手掌、箭头和三种时长类型之间切换。旧谱面的左右出拳保持为拳套。同拍且起止、类型相同的左右拳套在游戏中并排显示，保存和计数仍保留两个动作；双掌前伸是一颗独立动作。

方向盘中央的 **↔ 双臂展开** 表示左手向左、右手向右，整体使用 BOTH 固定紫色，箭头中间连通。支持 TAP / HOLD / SWAY；时间轴以一个标记选中、拖动、改时长、复制或删除，两只手同步处理。换成普通方向箭头时回到 BOTH 同向动作；F / H 不拆开这个固定双手动作。

第 3 轨 **STEP / 踏步** 位于 ARMS 和 CALF RAISE 之间。绘制与选中事件的类型菜单依次为 **TAP、FOLLOW、FOLLOW SWAY、HOLD、SWAY、FREE SWAY**，所有选项可直接互换。左右箭头单独选择移动方向；用脚颜色可选 **L 左脚蓝色、R 右脚红色、BOTH 双脚紫色**，不提供 ANY。H 循环用脚，F 只反转方向；改变类型、拉长与复制都会保留用脚颜色。新录入默认 L，录谱中切换 H 影响下一颗音符。FREE SWAY 可选择双脚紫色，也保留左右脚颜色，不强制改色。

| 动作        | 含义                                                 |
| ----------- | ---------------------------------------------------- |
| TAP         | 用颜色指定的脚，朝箭头方向迈一步                     |
| FOLLOW      | 指定脚朝箭头方向跟上并拢，空心断线箭头               |
| FOLLOW SWAY | 跟脚并拢后持续摇摆，空心断线箭头与波浪长条           |
| HOLD        | 迈出后由指定脚单脚支撑，保持到尾端                   |
| SWAY        | 迈出后左右移动重心、扭腰                             |
| FREE SWAY   | 不指定迈步方向，原地自由摇摆；∞ 同样使用所选用脚颜色 |
| L2 / R2     | 一次跨两格；TAP、HOLD、SWAY 都支持                   |

长条互转保留起止时间、ID 和左右跨度；改成 FREE SWAY、FOLLOW 或 FOLLOW SWAY 后清除跨度。普通 TAP 改成长条时创建默认结束点，随后可以拖动调整。单次 FOLLOW 不显示延长手柄，不因拖动或普通 Alt 长按生成长条；可通过类型菜单转换为 FOLLOW SWAY 或普通 TAP／HOLD／SWAY。自由摇摆也能直接改回任一左右动作。反向、跨度与跨轨操作跳过 FREE SWAY；FOLLOW 与 FOLLOW SWAY 可以反向，不设置跨度、不跨轨。

旧 C、C HOLD、C SWAY 已全部移除。打开旧谱时删除这三类音符，不补时长、不生成替代音符；源文件仅在用户保存时更新。新 FREE SWAY 使用 `direction: "free"`，与旧动作无关。

编辑器只检查同拍冲突及长条未结束就开始下一步，不再依据已移除的合腿动作推断站位。点击提示可定位音符，检查不会改谱或阻止保存。

配色统一：提踵及侧收腹轨道底色为初音绿 `#39c5bb`，蹲起与播放按钮为粉色 `#f64e93`；ARMS 左手青蓝 `#35c9db`、右手粉红、双手紫色 `#b58aee`、未指定中性白 `#e7edf2`。STEP 所有类型可选左脚青蓝、右脚粉红、双脚紫色，SIDE CRUNCH 的左腿青蓝、右腿粉红，颜色与动作方向独立；箭头、长条和尾端同步使用用脚／腿颜色。两格音符使用双箭头；时间轴用条纹区分 SWAY，跟练用连续波浪长条。

长按判定使用实际按键持续时间，音符起止始终使用视频媒体时间。录入过程中切轨或换手／脚只影响下一颗音符；方向、用手／脚和修饰键在按下时锁定。STEP 的 Shift 修改跨度，ARMS 的 Shift/Alt 选择斜向。吸附后长条起止重合时，终点延伸至下一个网格点。

音符与跟练提示统一为英文：HOLD、SWAY、BALANCE HOLD、FREE SWAY。SPECIAL 预告为 GET READY，触发为 SPECIAL!，长条结束为 RELEASE。旧 SPECIAL 名称优先显示英文部分；无英文时使用图标对应的名称，保存的原始名称不变。

跨轨拖动保留方向、时长和 SWAY 属性。FOLLOW、FREE SWAY 与两格音符只属于 STEP；普通一格 L/R 可在左右三轨互拖。多选拖动保持行距，不能进入目标轨道时保留原轨道。SPECIAL 不参与方向翻转和跨轨移动。

**修改节拍段的 BPM / 第一拍位置只改变网格，不移动已写的动作。** 要改变动作时间，请多选后整体拖动，或主动“重新吸附”。整体移动 HOLD 保留原媒体时长，拉伸端点才改变长度。

草稿、发布谱面、曲绘与专辑设置保存在 maps。浏览器 localStorage 只保存音量、流速、布局及最近作品等偏好；清理它只会重置偏好，不删除磁盘作品。JSON 替换前保留上一版至曲目 `.wfp-backup`；中断的多文件保存通过同目录恢复记录完成。建议定期备份整个 maps 文件夹。

## 开发与验证

```powershell
npm run check          # TypeScript 严格检查与核心单元测试
npm run format:check   # 源代码格式检查
npm run build          # 可部署静态产物（dist/）
npm run test:e2e:quick # 3 条核心流程：媒体、五轨录谱、保存后恢复
npm run test:e2e       # 常规功能回归，不包含视觉及性能专项
npm run test:e2e:visual # 布局、画面、音符重叠等专项
npm run test:e2e:perf  # 性能与长期 BGM 恢复专项
npm run test:e2e:endurance # 267 秒合成视频完整播放，按需运行
npm run test:e2e:packs # 独立曲包集成验证（需要先 build）
npm run preview       # 预览构建产物，http://127.0.0.1:4173/
```

浏览器测试使用已安装的 Google Chrome 和独立临时浏览器上下文。常规、视觉与性能测试在专用 `127.0.0.1:4180` 启动 Vite，不复用用户的 5173，也不执行会重选本机演示视频的 predev。固定合成视频位于 `tests/fixtures/player/`；普通测试使用 60 秒小谱面，性能及整首测试使用 267 秒视频，不依赖本机 maps。合成素材验证媒体集成和稳定性，不能替代真实曲包或 M3 真机性能验收。素材已随项目提供，仅重新生成时需要 ffmpeg：`npm run test:fixtures`。

失败截图／trace 与 HTML 报告分别在 `artifacts/test-results/`、`artifacts/test-reports/`；视觉专项截图也保存在 artifacts，均被 Git 忽略。测试结束主动关闭本次启动的服务。4180 已占用时直接报错，不接管已有服务；各组串行运行。曲包专项沿用独立 4178 与隔离 maps 目录。测试分组及旧用例处理见 [测试维护说明](tests/README.md)。

`package-lock.json` 固定依赖解析结果。安装用 `npm ci`；升级依赖后重新执行检查、构建和相关浏览器测试。

## 当前范围

- 支持本地浏览器使用；源码同步到个人 GitHub 仓库，运行时不会上传谱面或视频。
- 没有评分、动作识别或独立游戏音轨；菜单频谱与背景律动使用实时音频分析。
- 当前提供一个 Pop Art 主题；桌面外壳和第二主题属于后续便利功能。
- 跟练画面采用折页专辑布局，保留五轨、16:9 视频与播放控制，暂停菜单提供继续、重开和返回选曲；SPECIAL 只在事件附近显示。
- 以 1920×1080 桌面构图为基准，小窗口菜单和游玩等比缩小，工作台独立紧凑适配；不同宽高比可能留边。
- 视频兼容性取决于浏览器解码器；应用不进行转码。

`docs/decisions.md`、`docs/verification.md` 与旧交接文件仅供历史追溯，不作为当前规范，也不要求随每次功能修改同步维护。
