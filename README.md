# Waifu Fit Player

个人使用的本地舞蹈视频跟练播放器与谱面编辑器。一个作品由谱面和关联视频组成，打开作品时一并恢复。React + TypeScript + Vite，共享一个播放实例；五轨提示以视频时间为准。

## 启动

本机已配置 Node.js 24。推荐 Chrome 或 Edge。

双击根目录的 **`start-demo.cmd`**，或者在项目目录运行：

```powershell
npm ci
npm run dev
```

打开 <http://127.0.0.1:5173/>。启动脚本只监听本机，不创建远程仓库、不上传文件。

- 首页点击 **体验示例作品**，再点击播放，即可跟练。
- 跟练页点击 **WORKBENCH** 返回工作台，可以修改示例或从 **新建** 开始。文件管理与编辑工具集中在工作台。
- `maps/` 中现有 MP4 会被准备为本地示例素材。这个过程优先创建硬链接，不改变源视频；不支持硬链接时复制。整个 `maps/` 目录（包括谱面和视频）仅保存在本地，不纳入 Git。
- 没有示例素材也可直接导入任意兼容 MP4。
- 示例谱覆盖现有歌曲，展示五轨、普通／HOLD／SWAY 与重复 SPECIAL，包含 STEP 左右踏步、单脚支撑、两格踏步、重心摇摆与独立自由摇摆。**它是功能演示谱，尚未逐拍校准视频编舞。** 示例 BPM 为 150、第一拍为 2000 ms，可自行编辑。

主要英文字体随应用打包，封面和手写装饰使用系统字体回退；运行界面不依赖远程字体或在线服务。视频音轨是唯一音乐来源，旁边的 MP3 不会被额外播放。

工作台右侧「曲目 → 视频偏移 / ms」可设置 **−1000～+1000 ms**，精度 1 ms：正值让视频与声音相对谱面延后，负值提前。支持归零，随作品保存和恢复；只改变播放时的相对位置，不改动已有音符、BPM 或网格参数。

## 跟练画面

跟练采用参考图中的折页专辑构图：左页为五条动作轨道，右页为视频，中央书脊、独立透视、纸板厚度与地面阴影形成开合感。粉色／青色背景、粗体封面和手写标题延续参考图风格。SPECIAL 出现时临时使用曲名栏，不额外占用轨道空间。

场景包含顶部舞台射灯、硬边纯色几何地板、有织纹和厚度的运动垫。两页围绕中央书脊分别旋转，外侧底边向前展开，形成可测量的空间夹角。专辑留出底部空间，前景不会遮挡轨道或拦截操作。背景素材随项目本地加载，生成提示词和素材路径见 [美术记录](docs/art-direction.md)。

跟练方向音符使用白色实心、粗荧光色边与细白外缘；普通方向和 STEP 共用箭头，两格踏步使用双箭头，FREE SWAY 使用 ∞。STEP 颜色表示用脚，方向由箭头单独表示。每轨只有一条中心线，不按密度拆行或缩小音符。跟练与工作台使用相同符号，TAP／FOLLOW／HOLD／SWAY／FREE SWAY 在同一菜单中互换。

STEP 的 FOLLOW 表示指定脚朝箭头方向跟上并拢：同大小、同配色的空心粗荧光断线箭头，尖端完整。它可自由放在任意拍点，仅支持 TAP；在类型菜单选择 `FOLLOW`，方向和用脚颜色单独选择，可与现有 STEP 动作互换。

左右 STEP SWAY 的光带中段带白色鞋底印，提示沿箭头方向滑过去；工作台使用相同鞋印。鞋印随音符移动，空间不足或接近其他标记时隐藏避让。FREE SWAY 仍表示原地摇摆，不显示滑步鞋印。

SQUAT 的 HOLD 中段显示上下两层白色粗线、约 120° 的宽角向下箭头头部，没有箭身；尺寸大于鞋印和手掌，提示保持蹲下。它固定在长条中点，到判定线时自然裁切消失；工作台预览和时间轴同步显示。

SIDE CRUNCH 作为重音动作使用更宽厚的初音绿箭头；TAP 带短收尖拖尾，临近判定的 650 ms 内有收紧的角形亮边。命中时白芯短闪、横向冲击光带与四枚斜向碎光快速展开再消散；HOLD / SWAY 开始与结束使用稍收敛的版本。爆发替换普通命中粒子，每轨同时最多一个，使用预烘焙的 32 帧小图集，播放时不新增实时模糊、阴影或独立计时器。暂停冻结、跳转直接按视频进度选帧；减少动态效果时保留静态淡出。素材可用 `node scripts/bake-crunch-impact.mjs` 重新生成。

HOLD 为直线荧光带，SWAY 为连续 SVG 波浪带，尾端是白色实心圆心、轨道色环与细白外缘。光带末端自然收尖；波浪相位按完整音符时长确定，剩余部分不会重新拉伸。只有时间精确首尾相接的长条共用交接点，有间隔或时间重叠的独立音符保留各自尾圆；重叠光带在其他动作标记周围留白。所有圆点与箭头位于光带之上。新箭头靠近判定线时，旧的保持提示让位；同时保持多条时，判定位置显示最近开始的动作，所有音符的时间与计分保留。暂停、跳转和变速仍使用视频时间。左侧五轨继续使用统一的纯色标签。

同轨 TAP 精确放在 HOLD / SWAY 的结束时刻时，会成为光带一体连接的尾端箭头。例如“向下 HOLD → 向上 TAP”直接提示蹲下保持后立即起身；不需要额外开关，原音符时间和计分保持独立。有间隔或重叠的音符不会自动连成一体。

左页统计栏的 `CALORIES — KCAL` 是占位，暂未计算卡路里。`FULL COMBO` 默认全部命中：TAP +1；HOLD / SWAY 起点 +1，从起点开始每持续半拍 +1，结束 +1。尾端和持续计数重合时只计一次尾端；不足半拍的长条仍计起点与结束。跨 BPM 段时按实际经过的拍数连续计算，所有轨道（包括 STEP 与 FREE SWAY）规则相同。持续时判定圈随计分半拍轻微脉冲。暂停冻结、跳转后重算，不使用独立累加计时器，也不增加按键判定。

SPECIAL 的白芯荧光、五轨飞入、爆发与持续提示使用本地预烘焙纹理；播放过程中不再为碎片、光环和符号计算实时模糊／阴影。爆发按媒体进度选取 50 帧纹理中的当前帧，暂停冻结、回拖重现，漏帧后直接显示最新位置。渲染通知上限为 60 Hz，视频和音频按原速度播放；所有谱面时间仍直接读取 `video.currentTime`，没有按帧累加的游戏时钟。

需要改动效果素材时运行 `node scripts/bake-special-sprites.mjs` 重新烘焙；这只在开发时运行，不占用游戏播放时间。

SPECIAL HOLD 由白芯符号、粉色荧光长带和白芯尾圆连接，青色细边作为强调。长度对应真实持续时间；符号到框停留，尾端继续前进，结束时汇合并使用既有释放演出。两张共享小纹理替换原倒计时圆环及 HOLD 的装饰彗尾／碎星，不新增实时滤镜或粒子。超长条只绘制可见部分；减少动态效果仍保留表示时长的长带。可用 `node scripts/bake-special-sprites.mjs --hold-only` 单独生成长带素材。

对照负载可在开发服务运行时执行 `node scripts/measure-special-hold.mjs 对照名称`，每组采集三轮真实 1080p 播放，结果保存到 `artifacts/对照名称.json`。测量时停止其他自动化浏览器任务；该压力场景同时包含五轨超长音符和重叠 SPECIAL，不能当作普通谱面的平均性能。

右页视频窗口固定为 **16:9**，播放控制收在其下方；Chrome 全屏也保持相同比例。视频始终完整显示，不裁切人物或拉伸画面。较窄的竖屏会将两页上下排列。工作台保持平面布局，切换时保留同一个视频元素、进度与播放速度。

跟练长条的光带与箭头／自由摇摆符号共用整体外轮廓，连接处不单独描边，白色实心动作符号仍保留。返回工作台会退出游戏全屏，保留视频进度。

项目远程仓库为 [Bracer9/Waifu-Fit-Player](https://github.com/Bracer9/Waifu-Fit-Player)，`main` 是当前开发与发布的主分支。提交本地修改后可直接运行 `git push` 同步。

## 完成一首谱面

1. **新建并选择视频**：选择本地 MP4 后创建完整作品；取消选择保留原工作区。默认完整显示画面，不裁切。建议 H.264 + AAC。
2. **设置网格**：编辑器右侧点“节拍段”，填写 BPM 与 4/4 或 3/4。拖动视频进度后点击“当前位置设为第一拍”。后续变拍或重新对齐时，在当前位置新增段。
3. **鼠标写谱**：使用铅笔工具，选轨道、方向和绘制类型（TAP / HOLD / SWAY）后点击或拖动时间轴。TAP 模式拖动空白处也可创建 HOLD；选中单个普通音符后，可向右拖动其右侧手柄直接延长为 HOLD，保留起点与方向，支持 STEP。选中音符，在右侧“类型”下拉菜单中转换 TAP / HOLD / SWAY；HOLD 与 SWAY 互转保留起止时间。拖动音符主体移动；同轴轨道 `1↔2`、`3↔4↔5` 可互拖；拖动长条两端改变长度。选中后按 `F` 或点击“反向”翻转方向。
4. **按键写谱**：启用“按键录谱”并播放。`1～5` 立即选轨，方向键点按录 TAP、长按录 HOLD、`Ctrl + 长按` 录 SWAY，松开结束。无需切换类型，可慢放逐轨叠加。
5. **SPECIAL**：在“曲目”面板启用并定义本曲唯一的招牌动作，在细 SPECIAL 行点击或拖长，可多次出现同一动作。跟练时，对应爱心／星星／闪光符号会在五轨同步飞入并爆发，持续 SPECIAL 在结束点再次散开。
6. **保存**：`Ctrl+S` 保存作品 JSON，包含谱面和视频关联；`Ctrl+Shift+S` 或下载按钮导出副本。支持文件保存对话框的浏览器可在本次会话继续写入已选择的文件；不支持时自动下载。
7. **跟练**：切换“跟练模式”，点击播放。所有动作提示自动到框；不需要按键，不计分。
8. **重开**：点击“打开作品”选择保存的 JSON，关联视频会自动载入。恢复草稿也会一起恢复视频。

## 作品与视频关联

- Chrome / Edge 使用本地文件引用，将引用记在当前浏览器中；不会复制整段视频，也不修改原视频。作品 JSON 保存稳定的视频关联 ID，不依赖同名文件猜测配对。
- 若浏览器询问读取权限，可选择“每次访问时允许”，以后自动载入；仅允许本次访问时，下次可能需要点击“允许读取视频”，无需重新寻找文件。权限行为见 [Chrome 官方说明](https://developer.chrome.com/blog/persistent-permissions-for-the-file-system-access-api)。
- 不支持文件引用选择器的浏览器，会把所选视频缓存在本地浏览器存储中，同样支持重开自动载入；这会额外占用相应磁盘空间。存储不足时会明确报错并保留当前作品。
- 旧版 JSON 第一次打开需要定位视频，重新保存后即可记住。视频被移动、删除、修改或关联记录丢失时，会显示定位窗口；取消打开保留原作品。
- 视频和谱面都验证完成后才切换作品，不进入只有其中一项的编辑状态。更换视频也必须通过媒体与时长检查，已有音符保持不变，编辑历史重新开始。
- 关联属于**当前浏览器资料和本地站点地址**。请固定使用 `http://127.0.0.1:5173/`；换浏览器、换端口、清理站点数据或将 JSON 拷到另一台电脑，需要重新定位一次。JSON 不内嵌视频，跨设备移动作品时也要携带 MP4。

## 编辑操作

工作台的“区间循环”用于反复预览同一段：两个标记都在时间轴上沿，拖动漏斗的**上半 A** 设置起点、**下半 B** 设置终点；重合时拼成完整漏斗，范围为空，自动关闭循环。拖开后开启“区间循环”并播放。范围跟随当前吸附设置，按住 Alt 拖动可精细调整；拖到边缘会自动横向滚动。视频与声音一起回到起点，支持暂停和变速，也兼容视频 offset。切换到跟练或打开另一首作品后退出循环；范围仅用于当前工作台，不写入谱面。

A / B 输入框可直接填写位置，回车确认：`1.128` 对应时间轴第 1 段第 128 小节，`1.128.3` 指定第 3 拍；单填 `128` 默认第 1 段。也可填 `03:12.500` 或 `192500ms` 精确定位，输入不受吸附限制。输入后自动显示对应时间并滚动至该标记。输入起点超过原终点时会顺带后移终点，方便直接换到很远的范围。

| 操作               | 方法                                                                          |
| ------------------ | ----------------------------------------------------------------------------- |
| 播放／暂停         | 空格或底部播放按钮                                                            |
| 选择轨道           | 录谱启用时 `1` 蹲起、`2` 提踵、`3` ARMS 手臂、`4` STEP 踏步、`5` 侧收腹       |
| 普通录入           | 方向键短按，松开写入一个 TAP，时间取按下时刻                                  |
| 保持录入           | 方向键按住至少 250 ms 自动录 HOLD，松开结束，不连刷                           |
| 摇摆录入           | 按下方向键时同时按住 Ctrl，长按录 SWAY HOLD                                   |
| ARMS 八方向        | ↑↓←→；Shift+←/→ 为 ↖/↗；Alt+←/→ 为 ↙/↘；也支持数字小键盘 789/46/123           |
| ARMS 正面出拳      | J 左拳套、K 右拳套；支持点按 TAP、长按 HOLD、Ctrl+长按 SWAY                   |
| ARMS 换手颜色      | H：ANY → L → R → BOTH；支持多选箭头，录谱时修改后续箭头的用手；拳套用 F 互换  |
| STEP 自由摇摆      | 第 4 轨按 ↓，点按放置一拍 FREE SWAY，长按决定时长                             |
| STEP 换脚颜色      | H：L 左脚蓝色 ↔ R 右脚红色；支持所有类型、多选与录谱，方向不变               |
| STEP 两格踏步      | Shift + ← / → 录 L2 / R2；可组合长按或 Ctrl + 长按                            |
| STEP 并步跟脚      | Alt + ← / → 录 FOLLOW；即使按住也只生成 TAP                                   |
| 修改踏步跨度       | 选中 L/R 按 D 或点击“跨度”；属性面板可将多选统一设为 1／2 格                  |
| 反转方向           | 选中一个或多个音符，按 F 或点击“反向”                                         |
| 跨轨移动           | 可拖往支持该方向的轨道；移入 ARMS 成为方向箭头，移出清除用手属性；斜向仅 ARMS |
| 多选／框选         | Shift 点选；选择工具拖动空白区域                                              |
| 复制／粘贴／剪切   | Ctrl+C / V / X；粘贴到当前视频位置并保留相对时间                              |
| 连续复制           | Ctrl+D 或属性面板“复制到后面”                                                 |
| 全选／删除         | Ctrl+A / Delete                                                               |
| 撤销／重做         | Ctrl+Z / Ctrl+Shift+Z 或 Ctrl+Y                                               |
| 保存／导出         | Ctrl+S / Ctrl+Shift+S                                                         |
| 取消选择、退出录谱 | Esc                                                                           |
| 时间轴缩放与滚动   | 缩放滑块、底部横向滚动条；“定位播放线”可立即回到当前位置                      |
| 吸附               | 每拍、半拍、四分之一拍或关闭；鼠标与录谱共用                                  |

文本与数值输入框内不拦截录谱快捷键。录谱开启后，方向键与 1～5 选轨优先于下拉框、按钮和滑块；不会因为选择吸附、类型或播放速度而失效。复选框、按钮和滑块获得焦点后，空格仍用于播放／暂停，不改变勾选状态。暂停、跳转、窗口失焦会取消尚未松键的录入，已完成的音符保留。

第 3 轨 **ARMS / 手臂** 提供八方向箭头与 L/R 拳套。箭头表达动作方向，可选 ANY 未指定、L 左手、R 右手、BOTH 双手；拳套表示对应手向前出拳，L/R 固定为蓝/红。F 反转方向或互换拳套，箭头的用手颜色不变；H 单独循环箭头用手，支持多选。TAP 为单次动作，HOLD 为到位后保持，SWAY 为持续摆动。绘制和属性面板共用方向盘，可在拳套、箭头和三种时长类型之间切换。旧谱面的左右出拳保持为拳套。同拍且起止、类型相同的左右拳套在游戏中并排显示，保存和计数仍保留两个动作。

第 4 轨 **STEP / 踏步** 位于 ARMS 和侧收腹之间。绘制与选中事件的类型菜单仅有 **TAP、FOLLOW、HOLD、SWAY、FREE SWAY**，所有选项可直接互换。左右箭头单独选择移动方向；用脚颜色仅有 **L 左脚蓝色、R 右脚红色**，不提供 ANY 或 BOTH。H 切换用脚，F 只反转方向；改变类型、拉长与复制都会保留用脚颜色。新录入默认 L，录谱中切换 H 影响下一颗音符。

| 动作       | 含义                                                  |
| ---------- | ----------------------------------------------------- |
| TAP        | 用颜色指定的脚，朝箭头方向迈一步                      |
| HOLD       | 迈出后由指定脚单脚支撑，保持到尾端                    |
| SWAY       | 迈出后左右移动重心、扭腰                              |
| FREE SWAY  | 不指定迈步方向，原地自由摇摆；∞ 同样使用所选用脚颜色  |
| L2 / R2    | 一次跨两格；TAP、HOLD、SWAY 都支持                    |

长条互转保留起止时间、ID 和左右跨度；改成 FREE SWAY 或 FOLLOW 后清除跨度。普通 TAP 改成长条时创建默认结束点，随后可以拖动调整。FOLLOW 不显示延长手柄，不因拖动或长按生成长条；可通过类型菜单转换为普通 TAP／HOLD／SWAY。自由摇摆也能直接改回任一左右动作。反向、跨度与跨轨操作跳过 FREE SWAY；FOLLOW 可以反向，不设置跨度、不跨轨。

旧 C、C HOLD、C SWAY 已全部移除。打开旧谱时删除这三类音符，不补时长、不生成替代音符；源文件仅在用户保存时更新。新 FREE SWAY 使用 `direction: "free"`，与旧动作无关。

编辑器只检查同拍冲突及长条未结束就开始下一步，不再依据已移除的合腿动作推断站位。点击提示可定位音符，检查不会改谱或阻止保存。

配色统一：提踵／侧收腹为初音绿 `#39c5bb`，蹲起与播放按钮为粉色 `#f64e93`；ARMS 左手青蓝 `#35c9db`、右手粉红、双手紫色 `#b58aee`、未指定中性白 `#e7edf2`。STEP 所有类型都是左脚青蓝、右脚粉红，箭头、长条、尾端和消失反馈同步使用用脚颜色。两格音符使用双箭头；时间轴用条纹区分 SWAY，跟练用连续波浪长条。

长按判定使用实际按键持续时间，音符起止始终使用视频媒体时间：0.5 倍速按住一秒，长条约占视频半秒。录入过程中切轨或换手／脚只影响下一颗音符；方向、用手／脚和修饰键在按下时锁定。STEP 的 Shift 修改跨度，ARMS 的 Shift/Alt 选择斜向。吸附后长条起止重合时，终点延伸至下一个网格点。

音符与跟练提示统一为英文：HOLD、SWAY、BALANCE HOLD、FREE SWAY。SPECIAL 预告为 GET READY，触发为 SPECIAL!，长条结束为 RELEASE。旧 SPECIAL 名称优先显示英文部分；无英文时使用图标对应的名称，保存的原始名称不变。

跨轨拖动保留方向、时长和 SWAY 属性。FOLLOW、FREE SWAY 与两格音符只属于 STEP；普通一格 L/R 可在左右三轨互拖。多选拖动保持行距，不能进入目标轨道时保留原轨道。SPECIAL 不参与方向翻转和跨轨移动。

**修改节拍段的 BPM / 第一拍位置只改变网格，不移动已写的动作。** 要改变动作时间，请多选后整体拖动，或主动“重新吸附”。整体移动 HOLD 保留原媒体时长，拉伸端点才改变长度。

谱面修改后会保留一个浏览器本地恢复草稿。它不是文件保存的替代品：浏览器清理网站数据后草稿可能消失。重新进入工作台可一起恢复草稿和关联视频。

谱面使用 `schemaVersion: 1`；时间是非负整数毫秒。五轨依次为 `squat`、`calf_raise`、`punch`、`step`、`side_crunch`。ARMS 保留内部轨道 ID `punch`；`armAction: "reach"` 表示八方向箭头（含 `up_left`、`up_right`、`down_left`、`down_right`），可选 `hand: "any" | "left" | "right" | "both"`；`armAction: "punch"` 仅使用 `left/right`，拳套用手由方向决定。旧谱中缺少 `armAction` 的左右动作仍为拳套。STEP 支持 `left` / `right` / `free`；`distance: 1 | 2` 仅用于 L/R，缺省为 1。`free` 必须为 `kind: "hold", modifier: "sway"`，不能携带跨度。旧 `close` 的全部变体在读入时删除，不转换。SWAY 使用 HOLD 的 modifier；SPECIAL 使用曲目级定义与多个事件。未知版本、重复 ID、非法方向／跨度、无效长条和越界时间会明确报错。

FOLLOW 使用 STEP 左右 TAP 上的可选 `follow: true`，不能携带 `distance`、`endTimeMs` 或 `modifier`。旧谱不含该字段时行为不变；计分沿用 TAP 的 +1，不引入新的时钟或特效。

STEP 所有类型支持 `foot: "left" | "right"`，与方向、跨度和时长独立，保存时保留。旧谱没有此字段时左右方向沿用原来的蓝／红色；旧 FREE SWAY 默认左脚蓝色，可直接切换为右脚。跨到非 STEP 轨道时清除用脚字段。

播放器与编辑器共享同一谱面和视频实例。动画只读取 `video.currentTime`，不积累第二个时钟，不用独立定时器触发音符。保持状态、命中闪光和 SPECIAL 在暂停和跳转后都由目标媒体时间计算。

音符到框与长条结束时显示约 520 ms 的局部反馈：亮芯收缩、扩散光圈、八枚碎光、短十字闪光与局部光晕；长条结束的光圈略大。效果仅在判定附近，没有额外音效或画面震动。暂停时冻结，跳转按目标媒体时间重算；系统启用减少动态效果时隐藏粒子、闪光与动态光晕，并关闭缩放和持续脉冲。

SPECIAL 使用更醒目的独立演出：五轨各出现一个白芯荧光符号，按照该事件所在 BPM 与“预告 / 拍”同步到框；到框后显示约 820 ms 的双色光环、放射闪光、符号残影与彩色碎星。持续事件以连续长带和尾圆表示剩余时间，结束后再次爆发。效果限制在轨道内，不遮挡视频，也不增加音效或震屏。暂停、回拖、变速和连续事件均由视频时间决定；减少动态效果时保留符号、时长长带与静态淡出，隐藏装饰拖尾和碎星。

## 当前范围

- 支持本地浏览器使用；源码同步到个人 GitHub 仓库，运行时不会上传谱面或视频。
- 没有评分、动作识别、音频分析、自动 BPM 检测或独立音轨。
- 当前提供一个 Pop Art 主题；桌面外壳和第二主题属于后续便利功能。
- 跟练画面采用可回退的折页专辑布局，保留五轨、16:9 视频、播放控制及返回工作台入口；SPECIAL 只在事件附近显示。
- 1280×720 可用，编辑器在较矮窗口中需要页面向下滚动。1920×1080 可同时查看预览与编辑区。
- 视频兼容性取决于浏览器解码器；应用不进行转码。

详细行为依据保存在 `Waifu-Fit-Player_Codex_Handoff/CODEX_HANDOFF_UPDATED.md`。其中首轮“只规划”的限制已被用户明确授权实施替代。
